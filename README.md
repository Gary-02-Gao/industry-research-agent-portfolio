# 行业信息研究智能体

**项目作品集**

本仓库为精选源码与成果展示包，不包含完整应用、原始报告或模型服务。可浏览演示并运行下方离线核验；macOS 本地展示启动步骤见 [本地运行说明](本地运行说明.md)。

面向行业报告与企业资料的可追溯问答系统，围绕**评测数据集建设、数据质量校验、混合检索与工具路由**，实现从数据准备到系统评测的工程流程。

## 项目亮点

- **可追踪的数据集建设**：构建 IndustryBench-100，覆盖事实查询、多跳推理、跨文档比较和不可回答问题；通过来源定位、Schema 校验、哈希与分层划分管理数据质量。
- **文档范围感知检索**：已知报告优先词法检索，范围未知时融合向量与词法排序，兼顾跨文档证据覆盖。
- **统一的工具路由契约**：运行时与评测共享策略，将工具选择、参数校验和执行结果分别记录。
- **答案与证据对照**：前端展示研究过程、回答结果和来源片段，支持逐项核对关键事实。

## 代表性成果

| 工作 | 结果 | 实验设置 |
| --- | --- | --- |
| 数据集建设 | IndustryBench-100，100 题 | 四类任务 40/30/20/10；开发/验证/测试 40/30/30 |
| 检索对照 | Recall@10：60.6% → 98.6%；Precision@1：38.9% → 72.2% | 固定 20 题切片中的 18 道可回答题 |
| 工具选择 | 193/200，96.5%；Schema 合法 200/200 | 内部合成 ToolBench-200，共享策略 v6 |
| 批处理调度 | 200 请求：89.1 秒 → 8.9 秒 | 同模型、同数据；串行对比 16 并发的批处理总耗时 |
