# 数据工程导读

## 数据建设目标

行业问答涉及公司、年份、数值和指标口径等多个维度。项目将问题定义、证据来源与评分标准纳入统一数据结构，使检索和模型策略可以在固定输入下进行对照评测。

## 数据处理流程

来源身份与哈希 → 候选问题与证据整理 → Schema/类别/来源校验 → 分层划分与版本冻结 → 固定切片实验 → 分项评分。

| 环节 | 实现方法 | 代码入口 |
| --- | --- | --- |
| 数据结构 | 问题、任务类型、可回答性、工具范围、证据列表 | `../03_核心代码/evals/datasets/industry_bench_100.schema.json` |
| 证据溯源 | 文档标识、文件哈希、物理页码、证据片段和稳定 ID | Schema 与 `build_industry_bench_100.py` |
| 质量校验 | 字段约束、类别配额、原文匹配、重复片段一致性 | `build_industry_bench_100.py` |
| 数据切分 | 按任务类别分层，分配到开发、验证和测试集 | 构建器中的 `_split_ids` |
| 评分 | 检索覆盖、工具选择、参数合法性 | `../03_核心代码/evals/metrics/`、`toolbench_run.py` |

## 数据集设计

IndustryBench-100 包含 40 道事实题、30 道同文档多跳题、20 道跨文档比较题、10 道不可回答题。按类别分层划分为开发集 40 题、验证集 30 题、测试集 30 题。类别与划分统计见 `dataset-summary.json`。

证据记录保留来源文件、物理页码、片段文本及文件哈希；构建过程自动校验结构、配额和来源一致性。基准评测数据与模型请求分开组织，评分标签用于结果计算。

## 表格证据处理

PDF 表格抽取可能将年度表头和数值拆散。构建器将经审核的表格转录拆回可定位的原文证据片段，逐项检查对应页码与文本，并保留修复规则供审阅。这使表头、时间口径和数值关系能够沿来源追踪。

## 实验结果与分析

文档范围路由将明确指定报告的请求交给词法排序，范围未知时融合向量检索；结合跨文档候选分配，改善比较问题的证据覆盖。在固定 20 题切片的 18 道可回答题上，Recall@10 从 60.6% 提升至 98.6%，Precision@1 从 38.9% 提升至 72.2%。

## 后续研究

进一步完善按来源分组的划分策略、困难样本覆盖及字段级标注，结合独立评测分析数据选择和标注质量对模型效果的影响。
